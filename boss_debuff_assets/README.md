# 보스 디버프 (암흑 수류탄) 감지 에셋

## 폴더 구조

```
boss_debuff_assets/
├─ icons/dark_grenade/        아이콘 매칭 템플릿 (인게임 26x26 셀 크롭)
├─ timer_profiles/            남은 초 숫자 글리프 프로파일 (JSON)
├─ samples/
│  ├─ verified/               ← 눈으로 라벨을 확인한 타이머 ROI (번들 프로파일 학습 출처)
│  └─ screenshots/            ← 전체 스크린샷을 넣어 일괄 학습할 때 사용
└─ reference/                 아이템 아이콘 원본 등 참고용 (매칭에 사용 안 함)
```

## 1. 아이콘 템플릿 (`icons/dark_grenade/`)

보스 체력바 아래 디버프 칸을 **테두리까지 포함해 정사각형으로** 자른 PNG만 넣습니다.
1920x1080 / UI 배율 100%에서는 26x26px입니다. 여러 장 넣으면 모두 후보로 사용하며,
감지 시에는 16~46px 범위로 크기를 바꿔가며 찾으므로 다른 해상도·UI 배율도 커버됩니다.

새 템플릿을 자동으로 만들려면 (셀 좌상단 좌표와 크기를 알 때):

```bash
py tools/bootstrap_boss_debuff_assets.py <스크린샷.png> <cell_x> <cell_y> <cell_size> --label 9
```

> 주의: 우측 하단 배틀 아이템 단축키 칸에도 같은 아이콘이 보입니다.
> 그 아이콘은 렌더링이 달라 일치율 0.52~0.61에 머물고, 감지 영역도 보스 체력바 아래
> 디버프 줄로만 제한하므로 오탐되지 않습니다.

## 2. 남은 초 숫자 표본

인게임 숫자는 1080p에서 **높이 8px**밖에 안 됩니다. 인식은 다음 순서로 동작합니다.

1. ROI를 4배로 확대하고 **warm 채널(R-B) top-hat**으로 살몬색 글자만 남긴다.
   보스방 배경이 파랑/회색이든 밝든 같은 이진화 결과가 나오도록 임계값은
   그 프레임에서 가장 진한 획으로부터 유도한다.
2. 세로로 쪼개진 조각만 합치고(가로로 붙은 `17`은 합치지 않음), `초` 접미사를
   기준으로 왼쪽의 숫자들을 찾는다. 모든 판정 기준은 ROI 높이 비율이라
   해상도·UI 배율이 달라도 그대로 동작한다.
3. 글리프를 12x16 캔버스로 정규화해 HOG 최근접 이웃으로 분류한다.

번들 프로파일(`timer_profiles/dark_grenade.json`)은 `samples/verified/` 의 실측
프레임으로 학습되어 있고, leave-one-out 정확도가 1.00이라 설치 직후부터 숫자
인식이 켜집니다. 다른 해상도에서 어긋날 때만 아래로 다시 학습하세요.

### 방법 A — 앱에서 자동 수집 (권장)

`설정 → 보스 디버프 → 숫자 샘플 수집`을 켜고 암흑 수류탄을 **끝까지 사라질 때까지**
한 번 두세요. 라벨은 디버프가 **사라진 시점**에서 역산해 붙습니다. 살아 있는 추정값으로
라벨을 붙이면 잘못 추정한 값이 파일로 저장되고, 그 파일로 학습한 프로파일이 다시 같은
값을 확신하는 자기참조 고리가 생깁니다(v2.47 이전의 "계속 8초" 증상).

소멸 시점은 한 스캔 안에서만 알 수 있으므로, 저장 전에 카운트다운 위상을 맞춥니다.
각 프레임의 자리수가 라벨의 자리수와 맞아야 하고 2자리→1자리 전환이 9초에 놓여야
하므로, 관측이 중간에 끊긴 캐스트(보스 사망, 영역 이탈)는 한 장도 저장되지 않습니다.

그 다음 `샘플로 숫자 학습` 버튼을 누르면 프로파일을 **처음부터 다시** 만들고
leave-one-out 정확도를 재서 0.90 미만이면 신뢰하지 않습니다. 라벨이 오염된 샘플로는
학습이 통과하지 않으므로, 실패하면 샘플 폴더를 비우고 다시 수집하세요.

### 방법 B — 스크린샷을 폴더에 넣고 일괄 학습

파일명에 **화면에 보이는 남은 초**를 넣어 `samples/screenshots/` 에 저장합니다.

```
samples/screenshots/카멘_12s.png
samples/screenshots/카멘_9s.png
samples/screenshots/카멘_3s.png
```

그리고 아래 명령을 실행하면 아이콘 위치를 자동으로 찾아 숫자 영역을 잘라 학습합니다.

```bash
py tools/boss_debuff_calibrate.py --screenshots boss_debuff_assets/samples/screenshots
py tools/boss_debuff_calibrate.py --report        # 현재 학습 상태 확인
```

### 검증 도구

```bash
py tools/verify_timer_pipeline.py     # 실측 프레임 기준 세그먼테이션/정확도 측정
py tools/build_timer_seed.py          # verified/ 프레임으로 번들 프로파일 재생성
```
